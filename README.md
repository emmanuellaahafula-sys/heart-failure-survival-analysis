# Heart Failure Survival Analysis

Heart Failure Survival Analysis using Excel and Power BI.

## Project Overview

This project analyzes clinical records from a cohort of heart failure patients to explore survival outcomes and identify patterns across demographic and clinical factors.

The analysis focuses on patient survival, mortality, age groups, sex, and ejection fraction to provide an interactive view of recorded outcomes within the dataset.

## Objectives

- Analyze overall patient survival outcomes
- Compare survivors across different age groups
- Compare survivor counts by sex
- Examine survival rates across age groups
- Analyze average ejection fraction across age groups
- Build an interactive healthcare analytics dashboard in Power BI

## Dataset

The dataset used is the **Heart Failure Clinical Records Dataset**, containing 299 patient records and 13 clinical variables.

Key variables include:

- Age
- Anaemia
- Creatinine Phosphokinase
- Diabetes
- Ejection Fraction
- High Blood Pressure
- Platelets
- Serum Creatinine
- Serum Sodium
- Sex
- Smoking
- Follow-up Time
- Death Event

Dataset source:

- Kaggle: Heart Failure Clinical Records Dataset
- Original source: UCI Machine Learning Repository

## Key Insights

The analysis shows that:

- The dataset contains 299 heart failure patient records.
- 203 patients were recorded as survivors, while 96 experienced the recorded death event.
- The overall recorded survival rate is approximately 67.89%.
- Survival outcomes vary across age groups.
- Survivor counts differ between male and female patients in this cohort.
- Average ejection fraction varies across age groups.

These findings describe patterns within the available cohort and should not be interpreted as a clinical prediction model or as medical advice.
